# 03 — Machine Learning & Artificial Intelligence

Study notebooks, model implementations, and experiments covering **Classical Machine Learning, Deep Learning Theory & Frameworks, and Generative AI & Agents** as part of my PhD preparation in Quantum Computing and AI.

## Focus Areas

### 1. Applied Classical Machine Learning
- End-to-end ML workflows, data preprocessing, feature engineering, and cross-validation.
- Supervised learning (linear/logistic regression, SVMs, decision trees, random forests, gradient boosting).
- Unsupervised learning (clustering, dimensionality reduction, anomaly detection).

### 2. Deep Learning Theory & Frameworks
- Mathematical foundations of neural networks: backpropagation, regularization, optimization algorithms, and generalization theory.
- Architectures: MLPs, Convolutional Neural Networks (CNNs), Recurrent Networks (RNNs/LSTMs), and Transformers.
- Practical implementation across **PyTorch**, **fastai**, **Keras**, and **TensorFlow**.

### 3. Generative AI & Agents
- Large Language Models (LLMs), embeddings, and Retrieval-Augmented Generation (RAG).
- Building stateful, production-ready LLM applications and multi-step AI agents using **LangChain** and **LangGraph**.

## Reference Library

The notes and implementations in this directory are primarily based on:

- ***Hands-On Machine Learning with Scikit-Learn, Keras & TensorFlow* (*Mãos à Obra: Aprendizado de Máquina*)** — Aurélien Géron
  *Primary reference for applied classical machine learning pipelines, Scikit-Learn, and practical neural networks.*
- ***Deep Learning*** — Ian Goodfellow
  *Primary reference for theoretical foundations, optimization, and mathematical rigor in deep learning.*
- ***Deep Learning for Coders with fastai & PyTorch*** — Jeremy Howard & Sylvain Gugger
  *Primary reference for top-down practical deep learning, training techniques, and PyTorch workflows.*
- ***Generative AI with LangChain*** — Ben Auffarth & Leonid Kuligin
  *Primary reference for production-ready LLM applications, RAG architectures, and agentic systems with LangChain and LangGraph.*
