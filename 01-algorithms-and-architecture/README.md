# 01 — Algorithms & Software Architecture

Study notebooks, code implementations, and exercises covering **Data Structures, Algorithm Analysis, and Software Architecture** as part of my PhD preparation in Quantum Computing and AI.

## Focus Areas

### 1. Data Structures & Algorithm Analysis
- Asymptotic notation ($O$, $\Omega$, $\Theta$) and complexity analysis (time vs. auxiliary space).
- Recurrence relations, Divide and Conquer, and the Master Theorem.
- Core data structures (arrays, linked lists, stacks, queues, hash tables, trees, heaps, graphs).
- Sorting, searching, dynamic programming, greedy algorithms, and graph algorithms.

### 2. Software Engineering Practices & Architecture
- Clean, modular, and maintainable code design for research and production systems.
- Pragmatic engineering principles: orthogonality, DRY, decoupling, testing, and debugging.
- Technical architecture, system design trade-offs, and navigating complex engineering projects.

## Reference Library

The notes and exercises in this directory are primarily based on:

- ***Introduction to Algorithms* (CLRS)** — Thomas H. Cormen
  *Primary reference for formal algorithm analysis, proofs, and core data structures.*
- ***The Pragmatic Programmer*** — David Thomas & Andrew Hunt
  *Primary reference for software craftsmanship, design patterns, and maintainable engineering practices.*
- ***The Staff Engineer's Path*** — Tanya Reilly
  *Reference for technical architecture, big-picture system thinking, and leading complex technical initiatives.*
- ***The Engineering Executive's Primer*** — Will Larson
  *Reference for engineering strategy, organizational alignment, and technical decision-making at scale.*
