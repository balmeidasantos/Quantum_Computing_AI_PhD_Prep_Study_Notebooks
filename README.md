# Quantum Computing & AI — PhD Prep Study Notebooks

Study notebooks, code implementations, and exercises focused on building a solid computational foundation for a PhD in **Quantum Computing and Artificial Intelligence**.

## Overview

This repository documents my self-directed study journey across computer science fundamentals, mathematics, modern AI, cloud infrastructure, and quantum computing. Each notebook contains original summaries, mathematical derivations, and hands-on Python implementations.

## Study Tracks

### 1. Computer Science & Software Engineering
- **Data Structures & Algorithm Analysis:** Asymptotic notation (Big O, Omega, Theta), time/space complexity, and core algorithms.
- **Software Practices & Architecture:** Clean code, maintainable design, and engineering best practices.

### 2. Mathematics & Statistics
- **Linear Algebra & Multivariable Calculus:** Vector spaces, matrix decompositions, eigenvalues, gradients, and optimization.
- **Probability & Practical Statistics:** Distributions, statistical inference, and experimental design for data science.

### 3. Artificial Intelligence & Machine Learning
- **Applied Classical Machine Learning:** Supervised/unsupervised learning, feature engineering, and model evaluation.
- **Deep Learning Theory & Frameworks:** Neural network architectures, backpropagation, PyTorch, fastai, Keras, and TensorFlow.
- **Generative AI & Agents:** Production LLM applications, LangChain, and LangGraph.

### 4. Cloud Infrastructure & MLOps
- **Cloud-Based Architecture:** Scalable compute, distributed systems, and cloud-native design.
- **MLOps & Model Deployment:** Pipelines, versioning, monitoring, and serving models in production.

### 5. Quantum Computing
- **Quantum Mechanics & Qubits:** Superposition, entanglement, measurement, and state representation.
- **Quantum Algorithms & Circuits:** Gate-based quantum circuits, Grover's search, and quantum-classical hybrid approaches.
