# 04 — Cloud Infrastructure & MLOps

Study notebooks, infrastructure-as-code templates, and deployment pipelines covering **Cloud-Based Architecture** and **MLOps & Model Deployment** as part of my PhD preparation in Quantum Computing and AI.

## Focus Areas

### 1. Cloud-Based Architecture
- Cloud-native design patterns, compute orchestration (containers, Kubernetes), and distributed storage.
- Scalable training infrastructure: distributed data/model parallelism and GPU/TPU cluster management.
- Cloud-accessible quantum computing services (e.g., AWS Braket, IBM Quantum Cloud, Azure Quantum).

### 2. MLOps & Model Deployment
- End-to-end ML pipelines, experiment tracking, data/model versioning, and feature stores.
- Model serving architectures (REST/gRPC APIs, batch inference, edge optimization).
- Continuous training (CT), CI/CD for machine learning, and production monitoring (data drift and concept drift).
