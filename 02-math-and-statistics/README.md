# 02 — Mathematics & Statistics

Study notebooks, mathematical derivations, and Python implementations covering **Linear Algebra, Multivariable Calculus, Probability, and Practical Statistics** as part of my PhD preparation in Quantum Computing and AI.

## Focus Areas

### 1. Linear Algebra & Multivariable Calculus
- Vector spaces, linear independence, basis, rank, and linear transformations.
- Inner products, orthogonality, norms, projections, and matrix decompositions (Eigenvalues/Eigenvectors, SVD, PCA) — essential for both ML and quantum state representation.
- Vector calculus, gradients, Jacobians, Hessians, and continuous optimization (gradient descent, Lagrange multipliers).

### 2. Probability & Practical Statistics
- Probability distributions, random variables, expectation, variance, and Bayes' theorem.
- Exploratory data analysis, sampling distributions, bootstrapping, and confidence intervals.
- Statistical experiments, hypothesis testing, A/B testing, and regression diagnostics.

## Reference Library

The notes and exercises in this directory are primarily based on:

- ***Mathematics for Machine Learning*** — Marc Peter Deisenroth, A. Aldo Faisal & Cheng Soon Ong
  *Primary reference for linear algebra, analytic geometry, matrix decompositions, vector calculus, probability, and optimization.*
- ***Practical Statistics for Data Scientists* (*Estatística Prática para Cientistas de Dados*)** — Andrew Bruce & Peter Bruce
  *Primary reference for applied statistics, exploratory data analysis, sampling, and statistical experiments.*
- ***Deep Learning* (Part I: Applied Math & Machine Learning Basics)** — Ian Goodfellow
  *Supplementary reference for linear algebra, probability, information theory, and numerical computation in deep learning.*
